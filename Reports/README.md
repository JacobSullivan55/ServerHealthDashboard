# Server Health Dashboard

A PowerShell-based infrastructure monitoring tool that validates server health and generates reports.

## Features

- Imports server list from CSV
- Tests network reachability
- Validates DNS resolution
- Checks HTTPS availability on port 443
- Generates CSV reports
- Generates HTML dashboard reports
- Displays summary statistics
- Classifies systems as Healthy, Warning, or Critical

## Technologies Used

- PowerShell
- DNS Troubleshooting
- Network Connectivity Testing
- HTML Reporting
- CSV Data Processing
- GitHub Version Control

## Project Goal

This project was developed during the Microsoft Software and Systems Academy (MSSA) Server & Cloud Administration program to demonstrate automation, infrastructure monitoring, and reporting using PowerShell.
